해결하려는 문제

유튜브 영상으로 주식을 접하는 시청자는 많지만, 영상에서 언급된 종목이 그 뒤 실제로 어떤 수익률을 냈는지 확인할 방법이 없음

주요 화면 (3가지)

  • 이번 주 언급 급증 — 최근 언급이 늘어난 종목과 과거 반응
  • 언급 뒤에 — 5·20·60거래일 수익률 분포, 시장 대비 초과수익
  • 종목 타임라인 — 주가 차트 위에 언급 시점 표시

데이터 출처

  • YouTube Data API (20개 채널, 최근 1년)
  • DART (상장사 정보)
  • 공공데이터포털 · Yahoo · 업비트 (시세·지수)

특징

공개 API만 사용 · 채널을 A·B·C로 익명화하여 특정 유튜버에 대한 개인 평가를 피함

  • 시설/조건 비교 (업종, 부대시설, 반려동물, 예약 정보)
  • 일정별 날씨 결합 (4~10일 날씨·강수확률·최저/최고기온)
  • 캠핑 적합도 요약 (비·기온 조건으로 날짜 선택 지원)

데이터 출처

  • 한국관광공사 고캠핑 API (위치기반 · 기본정보 · 키워드 검색)
  • 기상청 중기예보 API (중기육상예보 · 중기기온)

구현 구조

Vercel (Client)→Render (API Server)→Supabase (PostgreSQL)

API 키는 서버에서 보관하고 외부 응답을 결합·정규화 · DB에 계획(camp_plans)·즐겨찾기·지역↔예보구역 매핑·API 캐시 저장
