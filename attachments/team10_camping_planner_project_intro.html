Team Project · Camping Planner

날씨와 캠핑장 정보를
한 화면에서 연결하는 캠핑 계획 도우미

캠핑장 검색과 날씨 확인을 한 화면에 묶어, 장소·일정·시설·날씨를 빠르게 비교할 수 있는 웹 서비스를 구현한다.

기상청 중기예보 API 한국관광공사 고캠핑 API Vercel + Render + Supabase
핵심 사용자 흐름
1. 조건 입력
지역 · 날짜 · 캠핑 유형
→
2. 후보 탐색
캠핑장 · 시설 · 위치
→
3. 계획 확정
날씨 · 강수 · 기온 확인

해결하려는 문제

01정보 분산캠핑장과 날씨 정보를 각각 검색해야 한다.
02일정 판단 어려움강수확률·날씨·기온을 날짜에 맞춰 따로 해석해야 한다.
03비교 불편시설·캠핑 유형·예약 정보를 한 번에 비교하기 어렵다.

구현하고 싶은 기능

주변 캠핑장 검색좌표·반경 기반으로 후보 캠핑장을 찾는다.
시설/조건 비교업종, 부대시설, 반려동물, 예약 정보를 비교한다.
일정별 날씨 결합4~10일 날씨·강수확률·최저/최고기온을 함께 표시한다.
캠핑 적합도 요약비·기온 조건을 간단히 요약해 날짜 선택을 돕는다.
예보 범위: 중기예보는 06시 발표 기준 4~10일, 18시 발표 기준 5~10일을 제공한다.
Architecture & Data Flow

클라이언트, API 서버, DB를 분리한 배포 구조

외부 API 키를 브라우저에 노출하지 않고, 데이터 결합·캐싱·사용자 저장 기능을 서버 계층에서 담당한다.

Vercel · Client 웹 UI 정적 배포/SSR 영역
  • 검색 조건 입력
  • 캠핑장·날씨 UI 표시
Render · API Server 외부 API 연동 및 조합 계층
  • API Key 보관 및 외부 API 호출
  • 응답 결합·정규화
Supabase · DB PostgreSQL 기반 영속 데이터
  • 계획·즐겨찾기·캐시
  • 지역 ↔ regId 매핑
